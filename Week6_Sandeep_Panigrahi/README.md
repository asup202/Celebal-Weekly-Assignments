# Image Denoising using Convolutional Autoencoder

## Project Overview

This project implements a Convolutional Autoencoder using PyTorch to remove Gaussian noise from MNIST handwritten digit images.

## Features

- Image Denoising using Autoencoder
- CNN-based Encoder and Decoder
- Gaussian Noise Addition
- Image Reconstruction
- Training Loss Visualization

## Dataset

MNIST PNG Dataset

## Technologies Used

- Python
- PyTorch
- Google Colab
- Matplotlib
- NumPy

## Files

- Autoencoder.ipynb - Complete project notebook
- best_model.pth - Trained model
- loss_curve.png - Training loss graph
- reconstruction_results.png - Output comparison

## Output

The model reconstructs clean images from noisy MNIST images using a convolutional autoencoder.
